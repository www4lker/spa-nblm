# Oficina NLM

Páginas autossuficientes (HTML sem etapa de build) que montam prompts para o
NotebookLM: Suite (system prompt e refinamentos), Dossiê de Confronto,
Laboratório e Prompt Studio. A página inicial é `index.html`.

Para usar, abra `index.html` no navegador. O texto digitado fica guardado só
no navegador de quem usa (`localStorage`); o botão "Limpar campos" o apaga.
